# Stage 248 · Class fields with 32-bit enum addresses

A writable class field declared as a signed or unsigned 32-bit enum uses the existing Int32 managed location. Metadata binding retains the declared enum type and the projection keeps the original object alive. The reduced pointer verification type allows the existing scalar load and store helpers to serve ordinary `ref` and `out` calls, including the original `ResourceManager` fallback-location field. Narrow and wide class enum addresses receive compiler diagnostics.

Run `npm run demo -- stage-248-int32-enum-class-field-projection` with the generated compiler from `npm test`, or set `STANDARDWASM_COMPILER_PATH` to a frozen compiler. The ordinary DLL compares signed aliases, unsigned high bits, separate objects and fields, a value-field control, and typed null handling on Windows x86, Node, and Edge. The runner also checks the located narrow- and wide-field diagnostics. Results and hashes go to `artifacts/stage-248-int32-enum-class-field-projection/results.json`.
